## Complete Register of Technical & Environmental Limitations

| ID | Domain | Implemented & Verified Capability | Exact Remaining Limitation |
|---|---|---|---|
| **LIM-01** | **RFID Hardware (Staff Pad, Handheld Wand & Security Gate)** | Full Python FastAPI middleware (`rfid-service/`) and 9 device-neutral backend adapters (`adapters.service.ts`) with EPC validation, duplicate filtering, shelf reconciliation, visible/audible handheld confirmation metadata, EAS bit inspection, and bidirectional footfall counting. | Runs in deterministic software emulator mode (`MOCK_RFID_MODE=true`). Physical Feig/Zebra HF/UHF pads, Chainway C72 handheld readers, and Impinj Speedway LLRP gates are not physically connected. |
| **LIM-02** | **Security Gate CCTV Integration** | Generates deterministic `cctvTimestampRef` tokens (`CAM-GATE-01_...`) and attaches usable 640×360 synthetic SVG camera snapshots (`image/svg+xml`, `data:image/svg+xml;base64,...`) via `GET /api/v1/rfid/gate-events/:id/cctv-snapshot` and the `CAMERA` adapter. | Synthetic SVG frame generation only; no physical IP camera or live RTSP/ONVIF NVR video stream is connected. |
| **LIM-03** | **Email, SMS & Print Slip Notifications** | Provider-neutral `EMAIL`, `SMS`, and `PRINT` adapters (`notifications.service.ts`) backed by the PostgreSQL `Notification` queue (`PENDING` → `SENT` / `FAILED` → `RETRY` → `SENT`), per-user channel preferences, and `AuditLog` entries. | Uses mock provider adapters (`externalDeliveryClaimed: false`). No live external SMTP relay, telecom SMS gateway, or physical ESC/POS thermal receipt printer is connected. |
| **LIM-04** | **NCIP 2.0 & 3M SIP2 Interoperability** | NCIP 2.0 (`/api/v1/adapters/ncip`) and 3M SIP2 (`/api/v1/adapters/sip2` with `AY` sequence numbers and `AZ` 16-bit checksums) execute live lookup, checkout, renewal, and check-in workflows through `CirculationService` with full policy enforcement and audit logging. | Implements the internal SmartLib adapter boundary and mock provider. Formal NISO NCIP 2.0 certification and live socket connection to an external third-party legacy ILMS are not claimed. |
| **LIM-05** | **Net Cataloguing Provider** | Provider-neutral `NetCataloguingProviderAdapter` (`/api/v1/opac/net-cataloguing/lookup` & `/import`) with metadata preview and `409 Conflict` duplicate ISBN prevention. | Uses `MockNetCataloguingAdapter` for deterministic offline/test execution rather than live Z39.50 / SRU external library consortium queries. |
| **LIM-06** | **Offline Deployment & Air-Gapped Database Operation** | Real non-dry-run execution of `install-offline.ps1` stages compiled `frontend/dist`, `backend/dist`, `prisma/schema.prisma`, and `rfid-service/` locally with SHA-256 verification (`installation-receipt.json`), and `rfid-service` buffers events in local SQLite (`offline_events.db`) without internet. | The Windows 11 host has no running local `postgres.exe` service (`C:\Program Files\PostgreSQL\18` has `data\` only) and no Docker daemon. Full air-gapped operation of the Express backend requires installing the local PostgreSQL 16/17 Windows MSI installer on the host. |
| **LIM-07** | **PostgreSQL Backup & Restore Scope** | Real SQL DDL+DML dump (`data/backups/postgresql_real_dump_420155.sql`, SHA-256 `a9f21ab2...`), simulated destructive failure (`DROP TABLE circulations CASCADE`), and full relational restoration into a separate isolated PostgreSQL schema (`smartlib_pg_rst_420155`). | Restores into a separate isolated schema on the same managed Neon PostgreSQL 18.6 server via Prisma raw SQL execution, rather than a bare-metal `pg_dump.exe`/`pg_restore.exe` across two separate database servers. |
| **LIM-08** | **Browser E2E Testing Environment** | Frontend pages and workflows are verified via 25 Vitest + React Testing Library tests (`frontend/src/tests/*.test.tsx`) and production Vite build verification (`npm --prefix frontend run build`). | Headless Chromium Playwright browser automation was not executed in this terminal audit session. |
