## 2. Explicit Production Limitations Disclosure

To ensure academic and professional honesty, the following constraints are formally declared for AISYS evaluators:

1. **Hardware Emulation Mode (`MOCK_RFID_MODE=true`):**
   - The RFID staff station, handheld scanner, and security gate operate via standards-compliant software emulation drivers (`staff_station.py`, `handheld_scanner.py`, `security_gate.py`).
   - Physical RFID antennas and tag chips are not required for demonstration.
2. **CCTV Synthetic Imagery:**
   - Security gate unauthorized transit events attach synthetic SVG camera snapshots (`640x360`) generated by the camera adapter, demonstrating media attachment without requiring physical IP cameras.
3. **Offline Air-Gapped Database Prerequisite:**
   - The offline installer stages container images, frontend assets, and Python middleware without internet. However, air-gapped operation without cloud Neon connectivity requires a pre-installed PostgreSQL 16+ instance on the host machine.
4. **Isolated-Schema Database Restoration:**
   - Database disaster recovery testing verifies isolated schema restoration on the running server rather than full physical operating system disaster bare-metal recovery.
